# ⚡ Password Generators - Streamlit Dashboard

A simple and modern Streamlit web application for generating three types of passwords:

- **PIN Generator**
- **Random Password Generator**
- **Memorable Password Generator**

---

## ✨ Features

### 🔢 PIN Generator
- Generate numeric PIN codes
- Length range: **4 – 32**

### 🔐 Random Password Generator
- Fully random passwords
- Length range: **8 – 100**
- Toggle to include **Symbols**
- Toggle to include **Numbers**

### 🧠 Memorable Password Generator
- Creates easy-to-remember passwords using words
- Number of words: **4 – 10**
- Custom **separator**
- Option for **Capitalization**
